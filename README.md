# 🤖 Claude Interaction Hub

Uma interface visual moderna e interativa projetada para melhorar a experiência de trabalho com o **Claude Code (CLI)**. Este hub transforma a interação via terminal em um dashboard organizado, com suporte a comandos de voz e gestão de projetos.

## ✨ Funcionalidades

-   **🚀 Gestão de Projetos:** Crie, organize e acompanhe o status dos projetos desenvolvidos com o Claude.
-   **🎙️ Reconhecimento de Voz:** Comande a interface usando a voz. O sistema captura sua fala e a prepara para ser enviada ao Claude.
-   **👩 Voz Feminina:** A interface responde a você com confirmações auditivas utilizando síntese de voz feminina em português.
-   **📝 Notas & Prompts:** Espaço dedicado para salvar prompts eficientes e anotações rápidas.
-   **📜 Log de Atividades:** Histórico completo de interações e comandos executados.
-   **💾 Persistência Local:** Todos os dados são salvos no `localStorage` do seu navegador, garantindo que suas informações estejam lá sempre que você voltar.

## 🛠️ Tecnologias Utilizadas

-   **HTML5** & **CSS3**
-   **Tailwind CSS** (Para um design moderno e responsivo)
-   **JavaScript (ES6+)**
-   **Web Speech API** (Reconhecimento e Síntese de Voz)
-   **GitHub Pages** (Hospedagem gratuita)

## 🚀 Como Instalar e Usar

### 1. Clonando o repositório
```bash
git clone https://github.com/SEU_USUARIO/interface-claude.git
cd interface-claude
```

### 2. Executando
Basta abrir o arquivo `index.html` em qualquer navegador moderno (recomendado: **Google Chrome** ou **Microsoft Edge** para melhor suporte a voz).

### 3. Usando a Voz
1. Clique no botão do **Microfone** no canto inferior direito.
2. Fale comandos como:
   - *"Novo projeto"* $\rightarrow$ Abre o modal de criação.
   - *"Notas"* $\rightarrow$ Navega para a seção de notas.
   - *"Projetos"* $\rightarrow$ Navega para a lista de projetos.
   - *"Logs"* $\rightarrow$ Abre o histórico de atividades.
3. Qualquer outra frase dita será copiada automaticamente para sua área de transferência, pronta para ser colada no terminal do Claude Code.
